# Outreach Emails — Usage Notes

Each file is a ready-to-send pitch for converting an existing ESIA/ESMP
client into a compliance care plan client. Before sending:

1. Fill in every `[bracket]` — the project name, facility type, approval
   date, and recommended tier come from that client's actual file, not
   from this template.
2. Send at (or right after) a natural touchpoint: final ESIA/ESMP report
   handover, a contract-close call, or a check-in ahead of their permit
   renewal — not as a cold, out-of-the-blue message.
3. Attach the relevant tier from `../pricing-tiers.md` as the quote.
4. If they say yes verbally, follow up same day with
   `../compliance-care-plan-agreement-template.md` filled in — don't let momentum cool.

The five files here (Abubaker Technical, Cosmic Investments, Kaletex
Ventures, Lusango Real Uganda, Crested Crane Timber) share the same
structure with light tailoring by likely facility type. Adjust the
tailoring if it doesn't match what EEIS actually scoped for that client.
