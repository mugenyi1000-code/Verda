# Quarterly (or Monthly) Compliance Visit — Scope Checklist

Use this checklist on every compliance care plan visit so delivery is consistent
regardless of which EEIS staff member attends, and so the fixed fee stays
fixed. Attach the completed checklist to the client's compliance report.

## 1. Pre-visit
- [ ] Pull the client's NEMA approval conditions / certificate on file
- [ ] Pull the last visit's report and open corrective actions
- [ ] Confirm sampling points and access with the site contact
- [ ] Check permit/licence expiry dates due in the next 6 months

## 2. Effluent monitoring (if applicable)
- [ ] Sample at each approved discharge point
- [ ] Record flow, visual clarity, odor, any obvious contamination
- [ ] Submit samples for lab analysis (BOD, COD, pH, TSS, oil & grease, per
      the discharge standard applicable to the site)
- [ ] Compare results against National Environment (Standards for
      Discharge of Effluent into Water or on Land) Regulations limits

## 3. Air / dust monitoring (if applicable)
- [ ] Check stack emissions or fugitive dust sources (kilns, boilers,
      crushers, treatment plant)
- [ ] Spot-measure or sample per site's approval conditions
- [ ] Note visible dust control measures (water spraying, enclosure,
      windbreaks) and whether they're in use

## 4. Waste handling audit
- [ ] Inspect storage areas for hazardous vs. non-hazardous segregation
- [ ] Check labeling, containment, and spill-prevention measures
- [ ] Verify waste transporter/disposal records and licences are current
- [ ] Confirm any previous corrective actions have been closed out

## 5. Permit / certificate tracking
- [ ] Confirm NEMA certificate and any sector permits (water abstraction,
      effluent discharge, etc.) are current
- [ ] Flag any renewal due within 90 days and start the renewal packet
- [ ] Note any conditions of approval at risk of breach

## 6. Reporting
- [ ] Complete the compliance status report (visit findings, lab results,
      corrective actions, renewal status)
- [ ] Rate overall status: Green (compliant) / Amber (minor issues,
      action plan in place) / Red (breach risk, escalate immediately)
- [ ] Deliver report to client within 5 working days of the visit
- [ ] Log the visit, results, and next due dates in the tracker
      (`app/index.html`)

## Out of scope (quote separately)
- New ESIA/ESMP for an expansion or new project
- Incident investigation or spill response
- Representing the client in a NEMA enforcement action
- Any sampling frequency or parameter beyond what's listed in the client's
